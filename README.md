# Військова топографія — онлайн-курс

Встановлюваний вебзастосунок (PWA). Розміщення: скопіюйте вміст цієї папки в репозиторій GitHub і ввімкніть GitHub Pages (Settings → Pages → гілка main, папка / root).

Структура:
- `index.html` — відкриває версію, на якій зупинився учень (або найновішу);
- `versions.json` — список версій; нова версія = нова папка `v2/` + запис тут;
- `sw.js` — офлайн-кеш, кожна версія має свій кеш;
- `v1/` — курс версії 1.0.

Прогрес зберігається в браузері (localStorage `topo.progress`) і спільний для всіх версій, тож оновлення його не стирає.
